# مهارات وسائل التواصل الاجتماعي — النسخة العربية

ترجمة عربية للمهارات السبع عشرة في مستودع
[charlie947/social-media-skills](https://github.com/charlie947/social-media-skills)،
مأخوذة من الالتزام `d2e9487`.

## البنية

كل مهارة لها ملف `SKILL.ar.md` موازٍ في مسار يطابق المستودع الأصلي:

```
skills/<اسم-المهارة>/SKILL.ar.md
```

الملفان المرجعيان مترجمان كذلك:

- `skills/newsletter-voice/references/archetypes.ar.md`
- `skills/voice-builder/references/sample-content.ar.md`

النصوص الإنجليزية الأصلية غير معدّلة وتبقى في مستودعها.

## قرارات الترجمة

هذه ملفات مهارات تُنفَّذ آليًا، لا وثائق للقراءة فقط. لذلك جرى التمييز بين
النص الموجَّه للإنسان والحمولات الموجَّهة للآلة:

| العنصر | القرار | السبب |
|---|---|---|
| حقل `name` في الواجهة الأمامية | يبقى بالإنجليزية | معرّف يطابقه المُحمِّل |
| حقل `description` في الواجهة الأمامية | يبقى بالإنجليزية مع إضافة عبارات تفعيل عربية | الترجمة الكاملة تُعطّل التفعيل بالإنجليزية؛ الإضافة تتيح التفعيل باللغتين |
| متن التعليمات | مترجم بالكامل | هذا ما يقرأه النموذج ويتبعه |
| موجّهات توليد الصور | تبقى بالإنجليزية | حمولات تُرسل إلى نماذج الصور؛ ترجمتها تُضعف الناتج |
| حمولات `AskUserQuestion` بصيغة JSON | تبقى بالإنجليزية، مع صياغة عربية للأسئلة بعدها | مفاتيح وقيم تُمرَّر إلى الأداة |
| أسماء الملفات والمتغيرات والأوامر | تبقى بالإنجليزية | معرّفات في نظام الملفات وبيئة التشغيل |
| قاعدة "الإنجليزية البريطانية" | صارت "العربية الفصحى المعاصرة" | المقابل الوظيفي لضبط السجل اللغوي |

## إضافات تخص العربية

حيث كان النص الأصلي يفترض محتوى إنجليزيًا، أُضيفت إرشادات لا مقابل لها في الأصل:

- **موجّهات الصور** (`gemini-carousel`، و`quote-post`، و`youtube-thumbnail`،
  و`graphic-designer`، و`profile-optimizer`) تتضمن سطرًا يُلحَق عند كون النص عربيًا،
  يطلب العرض من اليمين إلى اليسار مع وصل الحروف الصحيح واختيار خط عربي مناسب.
- **`graphic-designer`** يوصي بخطوط عربية للمسار المبني على HTML/CSS ويضبط
  `dir="rtl"` مع محاذاة النص إلى اليمين.
- **`niche-research`** يضيف نسخًا عربية لاستعلامات بحث Google إلى جانب الإنجليزية.
- **`reels-scripting`** يضيف سطرًا لتفريغ الريلز العربية بالحرف العربي.
- **`voice-builder`** يشير إلى `sample-content.ar.md` بدلًا من النسخة الإنجليزية.
- **`newsletter-voice`** يشير إلى `archetypes.ar.md` بدلًا من النسخة الإنجليزية.

## تحفّظ على ملف العيّنات

ملف `sample-content.ar.md` مترجم، لكن الغرض منه استخلاص بصمة صوتية
(طول الجملة، والإيقاع، والعبارات المميزة). والترجمة تغيّر هذه البصمة بطبيعتها.
لبناء ملف صوت عربي دقيق، زوّد مهارة `voice-builder` بعيّنات مكتوبة بالعربية أصلًا
بدلًا من الاعتماد على هذه النسخة. التحفّظ نفسه مدوّن في رأس الملف.
